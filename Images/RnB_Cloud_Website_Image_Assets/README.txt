Implementation notes
--------------------
- Assets are WebP for direct web use.
- The caption/filename strips from the original planning board were removed.
- Use CSS object-fit: cover where a different aspect ratio is required.
- Preserve focal points when cropping on mobile.
- Add descriptive alt text for meaningful images. Decorative imagery should use empty alt text.
