# RnB Cloud website build brief

## Confirmed project direction

Rebuild rnbcloud.com as a professional, modern Louisville technology company website using Next.js App Router, TypeScript, and Tailwind CSS. Prepare for Vercel hosting. Keep core marketing content in code; add Resources/blog and a lightweight CMS such as Sanity after the core launch.

Use the supplied RnB Cloud logo artwork without redrawing or retyping it. Use Montserrat headings and Inter body/UI text, generous white space, restrained motion, and subtle cloud/network graphics.

Brand colors: navy #071D5C, deep blue #0E4AA2, cloud blue #0B79DA, electric blue #038FFA, cyan #0AB7F9, sky tint #A7CDE8, white #FFFFFF, charcoal #1D2733. Choose accessible foreground/background combinations.
